# YouTube Seek Edit

A tiny Firefox extension that lets you set how far YouTube's keyboard shortcuts seek.

- **← / →** — default 1 second
- **J / L** — default 1 second

Set either one as low as 0.1 seconds from the toolbar button or the add-on's Options page.

## Install for development

1. Open `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on…** and select `manifest.json`
